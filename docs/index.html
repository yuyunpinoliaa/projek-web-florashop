Dokumentasi Florashop

Panduan Penggunaan dan Informasi Sistem

1. Gambaran Umum Sistem

Nama Sistem: Web Florashop

Tujuan dan Manfaat: Platform penjualan bunga (florist) secara online untuk memudahkan pelanggan melihat katalog dan melakukan pemesanan.

Target Pengguna: Pelanggan (pembeli) dan Admin (pengelola toko).

Fitur-fitur yang Tersedia:

  • Katalog Produk Bunga
  • Detail Produk
  • Keranjang Belanja (Opsional/Sesuai fitur)
  • Dashboard Admin untuk manajemen produk
  • Sistem Autentikasi (Login/Logout)

2. Panduan Penggunaan Fitur (Alur Sistem)

A. Panduan Pelanggan

  1. Melihat Katalog: Pengguna membuka halaman utama (home) untuk melihat daftar bunga yang tersedia.
  2. Detail Bunga: Pengguna dapat mengklik salah satu produk untuk melihat detail lebih lanjut.

B. Panduan Administrator

  1. Login Admin: Admin mengakses halaman login dan memasukkan kredensial.
  2. Dashboard Admin: Setelah login, admin masuk ke dashboard.
  3. Kelola Produk: Admin dapat menambah, mengubah, atau menghapus data produk bunga dari database.
  4. Logout: Admin dapat keluar dari sistem dengan aman.

*Catatan: Panduan ini dapat disesuaikan lebih lanjut dengan alur sistem (flow diagram) yang sebenarnya.
