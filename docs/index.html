Panduan Penggunaan

Berikut adalah panduan lengkap cara menggunakan sistem Florashop, baik untuk pembeli maupun admin toko.

Panduan Pembeli (Pelanggan)

  1. Melihat Katalog: Kunjungi halaman utama untuk melihat daftar koleksi bunga.
  2. Detail Produk: Klik pada foto atau nama bunga untuk melihat informasi detail dan harga.
  3. Pendaftaran/Login: Buat akun baru atau login menggunakan akun yang sudah ada untuk bisa melakukan transaksi.

Panduan Administrator

  1. Login Admin: Akses halaman login khusus admin dan masukkan username serta password Anda.
  2. Dashboard: Setelah masuk, Anda akan diarahkan ke dashboard admin.
  3. Manajemen Produk: Anda dapat menambah bunga baru, mengedit harga/stok, atau menghapus produk dari katalog.

Desain & Arsitektur

Sistem ini dirancang dengan pendekatan arsitektur Client-Server yang sederhana namun handal. Antarmuka pengguna (UI) dibuat responsif agar dapat diakses dengan nyaman melalui perangkat desktop maupun mobile.

Teknologi yang Digunakan

  • Frontend: HTML5, CSS3, dan Vanilla JavaScript.
  • Backend: PHP Native.
  • Database: MySQL (Relational Database).
  • Server Lingkungan: XAMPP / Apache.

FAQ (Tanya Jawab)

Apakah sistem ini bisa digunakan di HP?

Ya, desain antarmuka sistem Florashop sudah dibuat responsif sehingga menyesuaikan dengan layar perangkat mobile.

Bagaimana cara admin mereset password?

Saat ini fitur reset password harus dilakukan langsung oleh Database Administrator melalui database MySQL. Fitur reset otomatis akan hadir pada update selanjutnya.
